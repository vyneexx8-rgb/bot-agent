# Telegram Business Autobot v3.5

Обычный бот через @BotFather с включённым **Secretary Mode / «Автоматизация чатов»**. Работает через официальный Telegram Bot API и получает доступ **только к чатам и функциям, которые разрешил владелец аккаунта**. Не запрашивает коды входа и пользовательские сессии.

## Установка и обновление

1. Установи Python 3.11+ и зависимости: `python -m pip install -r requirements.txt`.
2. В BotFather выбери **Bot Settings → Secretary Mode → On**. Подключи бота в настройках Telegram «Автоматизация чатов».
3. Скопируй `.env.example` в `.env` и впиши **свой токен BotFather** в `BOT_TOKEN`. Не присылай его никому. Для стороннего перефразирования текста требуется **новый, не опубликованный** ключ `GROQ_API_KEY`; прежний раскрытый ключ необходимо отозвать.
4. Запусти `python main.py`. Напиши боту `/start`. Для медиа потребуется Pillow; для видео и голосовых — установленный FFmpeg.
5. Дай боту необходимые разрешения: отвечать, удалять сообщения для мута, изменять имя/аватар для `.clone`, просматривать подарки для `.gifts`.
6. При обновлении **не удаляй старую базу `autobot.sqlite3` и свой `.env`**. Замени программные файлы из архива; структура базы расширится автоматически.

Если Telegram не передаёт исходящие сообщения владельца в Business-чате, отправляй команды из личного чата с ботом: `/run ЧАТ_ID .команда`. Например `/run 12345678 .chk`. Это ограничение Telegram, не ошибка клавиатуры.

## Обновление v3.5: отдельный мут стикеров

- **`.mutes 1ч`** — блокирует только новые стикеры собеседника на указанное время. Текст, фото, голосовые и остальные сообщения остаются доступны, если не действует обычный `.mute`.
- **`.unmutes`** — досрочно снимает мут стикеров. Обычный `.mute` не затрагивается.
- **Кнопка «🔓 Снять мут стикеров»** расположена прямо под сообщением в общем Business-чате, отображается обоим; воспользоваться может только владелец подключённого аккаунта. Сообщение о муте изменяется на том же месте при снятии и по истечении срока, если это разрешает Telegram.
- Время: `15m`, `30min`, `2 hours`, `1 day`, `15м`, `30мин`, `2 часа`, `1 день`, `1h30m`, `1ч 30м`. Допустимый срок от **1 секунды до 30 дней**. Русские и английские названия поддерживаются для всех длительностей.
- Из личного чата с ботом: `/mutes CHAT_ID 2 часа`, `/unmutes CHAT_ID`, `/muteslist`. Если исходящие Business-команды не доходят: `/run CHAT_ID .mutes 2 hours`.
- Для удаления стикеров нужно Business-разрешение **«Удалять все сообщения»**. Бот должен быть запущен, а Telegram должен предоставлять сообщения из соответствующего чата. Если клиент/API отклоняет удаление или редактирование, бот не сможет обойти ограничение.
- База `autobot.sqlite3` обновляется автоматически; при обновлении сохрани старый `.env` и базу данных.

## Новая версия: изменения

- Удалены `.bw`, `.leet` и `.yars` из меню и обработчиков.
- `.chk`: **«Мини шашки»**, поле **8×8**, 12 шашек на игрока, правило «фук» вместо обязательного первого взятия, взятие обычной шашкой назад, **дамки с дальним диагональным ходом**, превращение в дамку, **несколько последовательных взятий**, подсветка возможных ходов, строгая очерёдность игроков. Дамки обозначены ♕ и ♛. Игры хранятся в памяти и сбрасываются при перезапуске.
- `.duel`: приглашение обоим игрокам в общем чате с кнопками **Принять / Отказаться**, затем сказочная магическая дуэль по ходам, три очка здоровья, случайное попадание или промах, кнопка **Сдаться**, исход и возможность начать новый вызов. Это просто аркадная игра, без физического оружия и переводов средств.
- `.ttt`: сохранены крестики-нолики с очерёдностью, счётом и повторной игрой.
- `.kawai` / `.kawaii`, `.tsundere`, `.yandere`, `.bold`, `.italic`, `.monospace`, `.underline`: **повторная команда переключает тот же режим обратно в «выключено»**, другой режим заменяет предыдущий. `.styleoff` остаётся как дополнительный способ выключить стиль.
- `.clone`: временно заменяет **твоё** имя и фото на публично доступные имя/фото собеседника с заметной меткой **🎭**. Перед первой сменой делает резервную копию своих данных в локальной SQLite-базе. **`.restore`** восстанавливает своё имя и фото. Требуются права редактирования имени и фото, а также доступность аватара. Не копирует скрытые данные и не меняет чужой профиль. Если оригинальное фото недоступно для сохранения, его восстановление может быть ограничено настройками Telegram; рекомендовано заранее сохранить собственную фотографию отдельно.
- `.nk`: случайная иллюстрация неко-тян через публичный SFW API `nekos.best`. Для работы нужен интернет на сервере. При сбое показывает понятное сообщение об ошибке, а не текстового котика. Источник — семейно-дружелюбные иллюстрации.
- `.sparkle`: многострочная разноцветная пятиконечная звезда, рисуется сверху вниз и переливается, редактируя одно сообщение (как `.love`).
- `.dox` и `.info`: только доступные имя, username и Telegram ID; нет формулировок о номерах, адресах или скрытой информации.
- Прежний автоответчик, логи редактирования и удаления и мут с кнопкой «Анмут» сохранены. При снятии мута и по истечении срока бот старается **изменить первоначальное уведомление на месте**.

## Важные ограничения и конфиденциальность

- **Кнопки:** в общем Business-чате их видят оба участника; ход/действие проверяется по Telegram ID отправителя нажатия. Telegram иногда ограничивает отправку или изменение сообщений из-за разрешений и временного окна.
- **Редактирования/удаления:** логируются только сообщения, полученные в разрешённых чатах **после запуска**. Исходные тексты временно сохраняются в локальной базе, по умолчанию до семи дней. Скрытые/старые сообщения бот восстановить не может.
- **Переписывание стиля:** при настройке внешнего языкового сервиса исходящий текст передаётся этому провайдеру для обработки. Не используй это для секретов. Без `GROQ_API_KEY` работают упрощённые локальные стили. Ключи и файлы `.env` не входят в архив.
- **Профиль:** API не гарантирует доступ к фотографиям другого пользователя или текущему фото владельца. Образ с меткой 🎭 используется как узнаваемый костюм; функция не предназначена для выдачи себя за реального собеседника.
- Для работы расписаний и обновлений бот должен **быть запущен постоянно**. Работа с живыми серверами Telegram требует отдельной проверки с подключённым аккаунтом.

## Проверка

```bash
python -m compileall .
python -m unittest discover -v
```

Тесты шашек проверяют дамок, обратное взятие, правило «фук», комбо и превращение в дамку. Без установленных зависимостей `aiogram` тесты с Telegram-заглушками могут пропускаться. Это не означает, что подтверждена работа на настоящем Telegram-аккаунте.
